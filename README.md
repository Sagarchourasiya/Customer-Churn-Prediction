Customer Churn Prediction and Sales Dashboard

Project Overview:
The Customer Churn Prediction and sales Dashboard project leverages Data Analytics and Machine Learning to analyze customer behaviour, predict churn probabilty, and visualize sales trends. This system is essential for businesses, e-commerce platforms,service providers to enhance customer rentention and optumize sales strategies.

Key Features:
1. Data Acquisition and Preprocessing
   - collect customer data from crm systems, sales databases, and user interaction logs.
   - Perform ETL (Extract, Transform,Load)
   -  Handle missing values, normalize data, and encode categorical variables.
   -  Features engineering to extract purchase frequency, engagement scores, and subscription tenure.
  2. Churn Prediction Models:
     - Decision Trees and Random Forest
     - Gradient Boosting(XGBoost)
  3.Sales Trend Analysis
     - Track monthly, quarterly, and yearly sales growth.
     - Identify top-performing products/services.
     - Correlate churn trends with revenue impact.
  4. Interactive Dashboard and Insights
     - Real-time customer retention and churn analysis.
     - Sales visualization using heatmaps, bar charts, and line graphs.
     - Customers segmentation insights for targeted marketing.
